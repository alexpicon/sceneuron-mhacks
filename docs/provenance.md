# Project provenance

This is my account of how I planned and built Sceneuron.

![Planning, implementation, and hands-on testing](graphics/provenance.svg)

## How I built it

I spent a couple of hours drafting `PLAN.md` with Fable 5.1 on UltraCode. Once the plan was complete, I used GPT-6-Astra with ultra effort and ultrafast enabled to implement it before the deadline.

I set the product direction and will test the installed OBS and Stream Deck plugins before accepting the result. This testing gate is separate from automated builds and from Git author and committer metadata.

I also designed the final interface in Figma. The diagrams in this documentation use original SVG artwork and the dark surfaces, rounded panels, and accent colors visible in the current interface code. They are documentation graphics, not exports of the Figma frame.

## What the repository records

`PLAN.md` was the first committed file. Build output, local keys, and installed plugin copies are not source commits.

The [verification guide](verification.md) records the checks needed before I accept a commit candidate. The [product brief](project-brief.md) describes what the resulting product does.
